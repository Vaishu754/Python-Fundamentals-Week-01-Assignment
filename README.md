# 🐍 Python Fundamentals for Data Analytics – Week 1 Assignment

## 📌 Overview

This repository contains my **Week 1 Assignment** for the **Python Fundamentals for Data Analytics** course.

The assignment covers the fundamental concepts of Python programming, including variables, data types, operators, conditional statements, loops, functions, strings, collections, file handling, and a mini project.

---

## 🎯 Objective

The objective of this assignment is to build a strong foundation in Python programming by implementing basic programming concepts and applying them to solve real-world problems.

- Operators

- Loops (For & While)

- Student Record Management System
